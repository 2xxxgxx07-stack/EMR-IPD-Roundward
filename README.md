# IPD Tablet Web App - ระบบ To-Do List หอผู้ป่วยใน (Roundward)

เว็บแอปพลิเคชัน To-Do List สำหรับแท็บเล็ตพยาบาลและทีมแพทย์ในหอผู้ป่วยใน (IPD Tablet Roundward) ออกแบบ UI/UX ให้ตรงตามต้นฉบับระบบ EMR บน iPad อย่างสมบูรณ์แบบ ทั้งโทนสี ฟอนต์ การจัดวาง และฟังก์ชันการทำงาน

---

## 🌟 คุณสมบัติเด่น (Features)

1. **หน้าหลัก (Dashboard Overview & Animated 3D Nurse)**:
   - **ตัวละครพยาบาล 3D แอนิเมชั่น (Transparent Background)**: ขยับได้สมจริง เช่น หายใจ (Breathing/Floating), แขนโบกมือทักทาย (Waving Hand), ดวงตากระพริบและเปล่งประกายรอยยิ้มหวาน (Sparkle Smile FX) เป็นช่วงๆ โดยไม่มีพื้นหลังสีขาว
   - **Speech Bubble & Interactive Sound**: บอลลูนข้อความทักทายลอยเหนือพยาบาล สุ่มเปลี่ยนคำพูดให้กำลังใจทีมพยาบาลในวอร์ด และสามารถแตะ/คลิกเพื่อคุยพร้อมเสียง Chime ไพเราะ
   - **4 Dashboard Metric Cards (2x2 Grid)**:
     - **สิ่งที่ต้องทำ (To-Do List วันนี้)**: แสดงยอดรวม, รายการค้าง, เสร็จแล้ว และแถบความคืบหน้า (Progress Bar) พร้อมปุ่มคลิกไปที่ To-Do List ทันที
     - **Order ที่หมอสั่ง (Doctor Orders)**: สถิติคำสั่งใหม่, ด่วน Stat, และรอ Confirm
     - **ผู้ป่วยที่ต้องดูแล (Patients In-charge)**: จำนวนเตียงครอง Ward 5B, อัตราครองเตียง 100%, และเคสเฝ้าระวัง MEWS
     - **การส่งเวรพยาบาล (Nurse Handover)**: ความคืบหน้าการรับเวร, เคส Focus และ Note วิกฤต

2. **หน้า To-Do List (สไตล์ iPad Safari EMR)**:

2. **ระบบนับสถานะงานอัตโนมัติ (Live Status Counters)**:
   - บล็อกแสดงสถานะ **"ยังคงเหลือ"** (กล่องสีฟ้า ตัวเลขอัปเดตตามจริง)
   - บล็อกแสดงสถานะ **"เสร็จแล้ว"** (กล่องสีเขียว ตัวเลขอัปเดตตามจริง)
   - ระบบ **"เลือกทั้งหมด" (Select All)** ทำเครื่องหมายงานทั้งหมดได้ในคลิกเดียว

3. **รายการงานการพยาบาลพร้อมข้อมูลจริง (Clinical Focus Notes)**:
   - แสดงเวลา (เช่น 08:30 น.)
   - ตัวบ่งชี้ระดับความสำคัญ (Dot Indicator: วิกฤต, สูง, ปานกลาง, ต่ำ)
   - ปุ่มดูรายละเอียด (Eye Icon) และปุ่มลบ (Trash Icon)
   - มีข้อมูลตัวอย่างมาตรฐานงานวอร์ดครบถ้วน เช่น:
     - วัดและลงบันทึก Vital Signs + MEWS Score
     - เจาะ DTX ปลายนิ้วก่อนอาหาร
     - แจกยาและบริหารยาตามรอบ (e-MAR)
     - ทำแผลผ่าตัด / แผลกดทับ
     - พ่นยาขยายหลอดลม / Suction
     - พลิกตัวผู้ป่วยติดเตียงทุก 2 ชั่วโมง
     - ตรวจสอบฟิล์ม X-ray / CT Scan ในระบบ PACS
     - เตรียมผู้ป่วยก่อนผ่าตัด (Pre-op Checklist)
     - ฟีดอาหารสายยาง (NG Tube Feeding)

4. **Modal ครบ 3 รูปแบบตามต้นฉบับ**:
   - **Modal ดูรายละเอียด (View Details)**: แสดงวันที่ เวลา ระดับความสำคัญ หัวข้อ และ Nurse Progress Note (DAR format: Data, Action, Response) พร้อมปุ่ม `[แก้ไข]` สีเขียว
   - **Modal แก้ไขรายการ (Edit Task)**: แก้ไขวันที่ เวลา ความสำคัญ หัวข้อ และโน้ตบันทึก พร้อมปุ่ม `ยกเลิก` และ `บันทึก` (สีเขียว)
   - **Modal เพิ่มรายการ (Add Task)**: เพิ่มงานใหม่พร้อมจัดเก็บลงระบบ

5. **ระบบจัดเก็บข้อมูล (LocalStorage)**:
   - ข้อมูลงานและสถานะการเช็คจะถูกบันทึกไว้ในเบราว์เซอร์อัตโนมัติ ไม่สูญหายเมื่อรีเฟรชหน้าจอ
   - มีปุ่มคืนค่าข้อมูลเริ่มต้น (Reset Sample Data) ในเมนูโปรไฟล์

6. **ระบบค้นหาและกรองข้อมูลด่วน (Smart Filter & Search)**:
   - กรองตามสถานะ: ทั้งหมด / ยังไม่เสร็จ / เสร็จแล้ว
   - กรองตามรอบเวลา: 08:30, 11:30, 14:00, 17:30
   - ค้นหาแบบ Real-time ตามหัวข้อ, เตียงผู้ป่วย, หรืออาการ

7. **Sidebar Drawer นำทาง**:
   - คลิกปุ่ม Hamburger เมนูด้านซ้ายบน เพื่อเปิดแผงควบคุมหอผู้ป่วย (เตียงครอง, กราฟสัญญาณชีพ, บันทึกส่งเวร SBAR)
